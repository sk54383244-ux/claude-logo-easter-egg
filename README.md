# claude.ai 로고 연타 이스터에그 (Claude logo bounce easter egg)

claude.ai 웹에서 **Claude 로고(글자)를 연속으로 클릭하면 로고가 제자리를 떠나 화면 안을 DVD 대기화면처럼 벽에 부딪히며 돌아다니는** 현상을 발견해 기록합니다.

- 발견/기록일: 2026-11-18 (KST)
- 상태: **비공식. Anthropic의 공식 확인은 받지 못했습니다.** 같은 날 앱 내 피드백으로 제보했습니다.
- 재현 여부: 여러 번 재현됨

## 재현 방법

1. 웹 브라우저(Chrome, Windows 11)에서 claude.ai에 접속합니다.
2. 홈 화면(`claude.ai/new`)에서 **Claude 로고를 연속으로 8번 클릭**합니다.
3. 로고가 제자리를 떠나 화면 안을 튕기며 돌아다닙니다.

> 참고: 대화 중인 채팅 화면에서 시작하면 첫 클릭은 로고 클릭 기본 동작(새 채팅 / 홈으로 이동)에 쓰입니다. 그래서 채팅 화면에서는 총 **9번**, 이미 홈 화면이면 **8번**입니다.

## 영상

[`logo_bounce_blurred.mp4`](./logo_bounce_blurred.mp4) (64초)

- 노트북 화면 부분만 확대해 고정했고(손떨림 보정), 사이드바 등 개인정보가 보이는 부분은 블러 처리했습니다.
- 영상 초반(약 2초)은 채팅 화면이고, 로고를 누르면 홈 화면으로 넘어간 뒤 계속 클릭해 튕기는 모습이 나옵니다.

## 한계

- 클릭 횟수나 조건(간격 등)의 정확한 규칙은 제가 코드를 본 것이 아니라 직접 눌러보며 확인한 결과입니다.
- 웹(Chrome) 한 환경에서만 확인했습니다. 다른 브라우저나 앱에서의 동작은 모릅니다.
- 공식 이스터에그인지, 의도하지 않은 동작인지는 확인되지 않았습니다.
